# Minigames

Colección de minijuegos de navegador en HTML, CSS y JavaScript puros (sin dependencias ni build).

- **Vuelo en la Cueva**: espacio, ↑, clic o toque para aletear entre estalactitas; el hueco se cierra con los puntos.
- **Pong**: W/S, flechas ↑/↓ o ratón/dedo contra una IA; la pelota acelera y gana el primero en llegar a 7.
- **Zorro Veloz**: espacio, ↑ o toque para saltar rocas y troncos; mantén para saltar más alto y salta en el aire para doble salto.

Cada juego guarda tu récord en el navegador y corre a la misma velocidad en cualquier monitor.

## Cómo jugar

Abre `index.html` en tu navegador y elige un juego. En cada uno, el enlace "← Menú" regresa al inicio.
