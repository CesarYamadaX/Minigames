# Minigames

Colección de minijuegos de navegador en HTML, CSS y JavaScript puros (sin dependencias ni build).

- **Flappy Bird**: espacio, clic o toque para saltar entre las tuberías.
- **Pong**: W/S o flechas ↑/↓ contra una IA simple; la pelota acelera.
- **Dino Runner**: espacio, ↑ o toque para saltar cactus cada vez más rápidos.

## Cómo jugar

Abre `index.html` en tu navegador y elige un juego. En cada uno, el enlace "← Menú" regresa al inicio.
